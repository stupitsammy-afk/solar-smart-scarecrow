# Solar Smart Scarecrow

A solar-powered automated scarecrow designed to detect birds
and respond using sound and movement.

## Project Overview

The project combines mechanical design, electronics, sensors,
and Arduino-based control to create an automated bird-deterrent
system.

## Main Components

- Arduino Uno
- Ultrasonic sensor
- Sound sensor
- L298N motor driver
- DC motor
- Buzzer
- Solar panel
- Solar charge controller
- Battery
- Buck converter

## Circuit Design

The electronic circuit was designed and documented using KiCad.

## Skills Demonstrated

- Arduino
- Electronics
- KiCad
- Sensor integration
- Motor control
- System integration
